# 0001 — Chip references instead of plain-text @path tokens

Picking a row in the @ picker used to land a plain-text `@相对路径` token in the draft (the plain-text-reference decision, matching the harness's skill source); it now mints a chip reference (U+FFFC placeholder, basename label) whose codec serializes the full `@路径` token at submit time. The display wanted the input to show only the 名称, and a plain-text basename token cannot round-trip: the Host resolves tokens as literal cwd-relative paths (a basename token for a nested file silently attaches nothing) and duplicate basenames (`package.json`, `index.ts`) are genuinely ambiguous. The chip keeps the model form — and therefore the Host's `agent/pre-step` expansion — byte-identical to before, at the cost of coupling the client to the harness's occurrence pipeline (submit-time serialization, paste-upgrade matching) instead of the trivial text replacement.
